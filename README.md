# Essayage de lunettes

## Installation
    npm install
    ADMIN_PASSWORD=ton_mot_de_passe npm run dev     (Windows PowerShell : $env:ADMIN_PASSWORD="..."; npm run dev)

- Utilisateur : http://localhost:5173/
- Admin       : http://localhost:5173/admin.html  (mot de passe par défaut : admin123, à changer)

## Production
    npm start      # build + serveur unique sur http://localhost:3001

## Montures
PNG transparent, vue de face, recadré serré. Régler la ligne verte au centre des verres.
Les fichiers sont stockés dans data/ (à sauvegarder).
La caméra exige localhost ou HTTPS.
